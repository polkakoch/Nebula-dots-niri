# Nebula

[English](README.md) · **Русский**

**Мягкий стеклянный рабочий стол на [niri](https://github.com/YaLTeR/niri) — со своей рамкой вокруг экрана.**
Строка меню переходит в тонкую рамку вокруг экрана, а поиск, пункт управления, плеер и док
«вырастают» прямо из неё. Цвета по умолчанию берутся из обоев (Material You), анимации мягкие.
Всё настраивается мышкой из пункта управления, без правки конфигов.
Интерфейс на русском и английском — язык выбирается при установке и меняется в любой момент.

## Установка

Arch Linux или дистрибутив на его основе, niri 26 или новее.

**Из git**:

```sh
git clone https://github.com/polkakoch/Nebula-dots-niri.git
cd Nebula-dots-niri
./install.sh
```

**Из релиза**: скачайте `nebula-<версия>.zip` со страницы [Releases](https://github.com/polkakoch/Nebula-dots-niri/releases), затем:

```sh
unzip nebula-*.zip && cd nebula-*/ && ./install.sh
```

Установщик интерактивный (стрелки, `Пробел`, `Enter`):

1. **Язык**: English или Русский.
2. **Как ставить**: быстро (всё по умолчанию), выборочно или только конфиги без пакетов.
3. **Компоненты**: уведомления, блокировка и сон, kitty, fastfetch, буфер обмена, скриншоты,
   Bluetooth, цвета для Qt/KDE, btop, меню Dolphin, русская локаль, дополнение Claude
   (по умолчанию выключено).
4. **Тема** (с цветными образцами прямо в терминале), **стиль строки меню**.
5. **Клавиатура**: языки, клавиша смены (Caps Lock, Alt+Shift, Ctrl+Shift, правый Alt).
6. **Папка с обоями** (пустая — положу туда набор градиентных обоев) и **приколы**.
7. **Мастер настройки при первом входе** — да/нет.

Недостающие пакеты ставятся через pacman, а то, чего нет в репозиториях, — через AUR (yay/paru;
если помощника нет, установщик соберёт yay). Перед установкой текущие конфиги копируются
в `~/.config/nebula-backup/<дата>`, `./uninstall.sh` возвращает всё как было. Повторный запуск
обновляет Nebula и сохраняет ваши настройки.

Всё то же без вопросов — параметрами:

| Параметр | |
|---|---|
| `--auto` / `-y` | без вопросов, всё по умолчанию |
| `--custom` | сразу к выбору компонентов |
| `--lang ru` | язык интерфейса: `ru` или `en` |
| `--no-packages` | не трогать пакеты, только конфиги |
| `--theme tokyo-night` | тема (по умолчанию `matugen` — «Из обоев») |
| `--bar pills` | строка меню: `frame`, `floating`, `classic`, `islands`, `pills`, `notch`, `minimal` |
| `--layouts us,ru,ua` | раскладки клавиатуры |
| `--switch alt_shift` | смена языка: `caps`, `alt_shift`, `ctrl_shift`, `ralt` |
| `--wall-dir ~/Картинки/Обои` | папка с обоями |
| `--claude` | включить дополнение Claude |
| `--no-fun` | без пасхалок и приветствия |
| `--no-welcome` | не показывать мастер при первом входе |
| `--no-reload` | не перезапускать текущую сессию |

### Первый вход

После установки при первом входе в niri открывается **мастер настройки**: язык, тема, обои,
строка меню и док, клавиатура и тачпад, приколы — всё применяется на ходу. «Пропустить» закрывает
его насовсем; запустить снова — Поиск → «Первоначальная настройка» или `nb-shell welcome`.

## Что внутри

| | |
|---|---|
| **Строка меню** | Семь стилей: **Рамка** (панель переходит в рамку вокруг экрана), **Плавающая** (стекло с блюром), **Классика** (во всю ширину, полупрозрачная), **Острова** (три группы: слева, в центре, справа), **Таблетки** (каждый модуль отдельно), **Чёлка** (центр свисает из верхнего края и пропадает, когда там пусто), **Минимал** (без фона). Мышью: колесо на точках — столы, на заголовке — соседние окна, двойной клик по заголовку — развернуть, СКМ — закрыть; колесо на логотипе листает обои, СКМ по нему — случайные обои; клик по языку — раскладка, ПКМ по батарее — режим питания. Модули перетаскиваются между зонами прямо в пункте управления |
| **Уведомления** | Свои: каждое — отдельная стеклянная карточка с блюром ровно по её форме. Значок и имя программы, время, картинка (обложка, аватар), прогресс, кнопки действий. Наведите мышь — уведомление подождёт и покажет крестик; клик — действие по умолчанию, ПКМ — убрать все. История — в пункте управления, там же длительность, сторона экрана и звук. «Не беспокоить» пропускает только срочные |
| **Плеер** | Когда играет музыка, в центре панели появляются обложка и «название · исполнитель». Клик открывает большой плеер: фон и кнопки окрашиваются в цвета обложки, при смене трека всё плавно перетекает. Перемотка (без «заикания» Spotify: позиция отправляется один раз, когда отпускаете ползунок), громкость плеера, перемешивание и повтор, ссылка на трек |
| **Док** | Снизу, с автоскрытием: выезжает, когда подводишь мышь к низу экрана или стол пустой. Перетаскивание меняет порядок; утащишь закреплённый значок из дока — открепится, запущенный к закреплённым — закрепится. ПКМ — меню, СКМ — новое окно |
| **Поиск** (`Super+Пробел`) | Приложения (с учётом частоты запуска), действия и настройки, калькулятор, `>команда`, `~/путь`, поиск в интернете. `Ctrl+D` закрепляет приложение в доке |
| **Приколы** | В поиске: `пароль` (надёжный пароль в буфер), `помидор` (25 минут фокуса с «Не беспокоить»), `погода Москва`, `#ff8800` (цвет в rgb/hsl), `таймер 10 чай`, `монетка`, `2d6`, `шар <вопрос>`, `shrug` / `flip` / `кот` (каомодзи), `удиви меня` (случайные обои и схема цветов), пара ответов на вечные вопросы и код Konami. Плюс приветствие при входе и новые обои при каждом входе. Всё выключается в «Дополнениях» |
| **Пункт управления** (`Super+A`) | Wi-Fi и Bluetooth со списками, «Не беспокоить», ночной свет, «не засыпать», профиль питания, яркость и звук с выбором устройства, музыка, уведомления. Страницы **обои** (`Super+W`), **буфер обмена** (`Super+V`), **питание** (`Super+Esc`) и **настройки**: оформление, строка меню, рабочий стол, окна и анимации, управление, дополнения, экран, язык, дата и время, fastfetch, профиль |
| **Пилюли** | Громкость и яркость в строке меню сами плавно расширяются при изменении и показывают полоску |
| **Окна** | Без яркой рамки фокуса: неактивные окна чуть прозрачнее, вокруг тонкая обводка. `Super+F` — на весь экран поверх панели |
| **Анимации** | Открытие окна — «всплывание» (свой шейдер), закрытие — уменьшение с растворением, пружины без отскока. Скорость регулируется |
| **Часы на обоях** | Большие часы и дата на пустом столе: положение, размер, шрифт, насыщенность, цвет |
| **Темы** | «Из обоев» (matugen) + 21 готовая. Меняют цвета сразу везде: панель, оболочка, уведомления, рамки окон, терминал, fastfetch, экран блокировки, Qt-программы |
| **fastfetch** | Своя картинка: папка `~/Pictures/Fastfetch`, пункт управления → Fastfetch, `Super+Shift+A`, ПКМ по картинке в Dolphin |
| **Профиль** | Фото пользователя в пункте управления, на экране блокировки и входа; кадр выбирается прямо в панели |
| **Язык** | Русский и английский: «Настройки → Дата и время → Язык интерфейса» или первый шаг мастера. Переводятся оболочка, строка меню, уведомления, подписи горячих клавиш, экран блокировки и меню Dolphin |

## Клавиши

| Клавиши | Действие |
|---|---|
| `Super+Пробел` | Поиск |
| `Super+A` | пункт управления |
| `Super+Enter`, `Super+T` | терминал |
| `Super+F` | на весь экран поверх панели / обратно |
| `Super+Shift+F` · `Super+M` | развернуть колонку · до краёв без отступов |
| `Super+W` / `Super+Shift+W` | обои / случайные обои |
| `Super+Shift+T` | темы |
| `Super+V` | история буфера обмена |
| `Super+Shift+A` | следующая картинка fastfetch |
| `Super+N` · `Super+Shift+N` · `Super+Ctrl+N` | убрать уведомления · «Не беспокоить» · вернуть последнее |
| `Super+Esc` | питание |
| `Super+Shift+L` | заблокировать экран |
| `Print` · `Ctrl+Print` · `Alt+Print` | скриншот области · экрана · окна |
| `Super+Shift+S` | скриншот области с редактором (satty) |
| `Super+Q` | закрыть окно |
| `Super+Tab`, `Super+O` | обзор |
| `Super+1…9` / `Super+Ctrl+1…9` | перейти на стол / перенести окно |
| `Caps Lock` | смена языка |
| `Super+Shift+/` | все клавиши с подписями |

В большом плеере: `Пробел` — пауза, `←/→` — перемотка, `N`/`P` — трек, `Tab` — другой плеер.

## Настройки

Почти всё меняется в пункте управления (`Super+A` → «Настройки») и применяется сразу.
Хранится в `~/.config/nebula/settings.conf` (там же комментарии к каждому ключу). После ручной
правки выполните `nb-settings apply`.

Свои правки, которые не перезапишутся при переустановке:

- niri → `~/.config/niri/conf.d/user.kdl`, мониторы → `conf.d/outputs.kdl`
- mako (запасной демон уведомлений) → `~/.config/mako/user.conf`
- kitty: ваш `kitty.conf` не трогается, в конец дописывается одна строка `include nebula-theme.conf`

### Своя тема

Скопируйте любой файл из `~/.config/nebula/themes/` и поменяйте цвета: тема сразу появится
в поиске и пункте управления.

```sh
name="Моя тема"
mode=dark            # или light
bg=#1e1e2e  bg_alt=… surface=… overlay=…   # фоны от тёмного к светлому
fg=…  fg_dim=…  muted=…                     # текст
accent=…  accent2=…                         # акценты
red=… green=… yellow=… blue=… magenta=… cyan=… orange=…
```

### Перевод

Строки в коде написаны по-русски, английские версии лежат в `nebula/i18n/en.tsv`
(«русская строка<TAB>английская»). Нашли кривой перевод — поправьте строку там.

## Команды

```
nb-shell launcher · nb-shell panel [walls|clip|power|appearance|…] · nb-shell media
nb-shell restart                        перезапустить оболочку
nb-settings set <KEY> <значение>        то же, что переключатели в пункте управления
nb-settings set UI_LANG en|ru           сменить язык
nb-settings bar-layout "<слева>" "<центр>" "<справа>"   модули строки меню
nb-notif dnd | dismiss | clear | restore | test
nb-fetch next | prev | random | set <файл> | add <файлы…> | none
nb-avatar set <картинка> | remove
nb-wall set <файл> | random | next | prev | restore
nb-theme apply <id> | list | current
nb-osd brightness up|down|set N · nb-osd volume up|down|mute|set N
nb-power lock|suspend|logout|reboot|shutdown|profile
nb-greet --now                          приветствие
nb-shell welcome                        мастер первоначальной настройки
```

## Дополнение Claude (необязательно)

Выключено, пока его не отметить в установщике (`--claude`) или в «Настройки → Дополнения».
Без него в системе нет ни клавиш, ни пунктов меню Claude.

- `Super+Shift+C` — Claude Code в терминале или Claude Desktop, `Super+Ctrl+Shift+C` — продолжить
  последний разговор; в поиске `?вопрос` открывает Claude с этим вопросом.
- В Dolphin ПКМ по папке → **Claude**: открыть здесь, продолжить, «объяснить, что в папке»;
  по файлу — «спросить Claude про файл».
- Claude Desktop официально выпускается только в виде .deb-пакета. В «Настройки → Claude» его можно
  импортировать (официальный .deb распаковывается в домашнюю папку без root) или поставить пакет
  `claude-desktop` из AUR.

## Релиз

`tools/make-release.sh [версия]` собирает `dist/nebula-<версия>/` и `dist/nebula-<версия>.zip`
(+ `.sha256`) — только файлы проекта, без `.git` и кэшей. Перед упаковкой всё проверяется на
личные данные: имя пользователя, домашняя папка, имя компьютера, почта, ключи и токены.
Нашлось — сборка останавливается.

## Устройство

```
nebula/                 → ~/.config/nebula
  shell/                nb-shell: уведомления, рамка, док, часы на обоях, поиск, пункт управления,
                        плеер, мастер первого входа (Python + GTK4 + gtk4-layer-shell, один процесс)
  bin/                  скрипты; nb-shell — клиент, пишет команду в FIFO оболочки
  i18n/en.tsv           английский перевод
  themes/*.theme        палитры
  templates/            шаблоны цветов для программ + targets (куда класть)
  settings.conf         настройки по умолчанию
config/                 → ~/.config
  niri/  waybar/  swayidle/  hypr/hyprlock.conf  servicemenus/ (Dolphin)
```

- Уведомления рисует nb-shell (сервер `org.freedesktop.Notifications`): каждая карточка — своё
  layer-окно точно по размеру, поэтому блюр и тень niri ложатся ровно по ней. Если оболочка
  не запущена, D-Bus сам поднимет mako.
- `nb-theme apply` подставляет палитру в шаблоны и мягко перезагружает программы.
- `nb-settings` превращает settings.conf в `niri/nebula-settings.kdl` и `waybar/nebula-settings.{jsonc,css}`.
- Всё по событиям, без опроса: в покое оболочка, waybar и пилюли почти не тратят процессор.
